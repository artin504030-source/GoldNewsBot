# مرحله H — قالب‌ساز پیام تلگرام Gold Market

## هدف
تبدیل گزارش فارسی مرحله G به پیام HTML سازگار با Telegram Bot API، بدون اتصال شبکه و بدون ارسال پیام.

## پیاده‌سازی
- `apps/gold_market/telegram.py`: تابع `render_telegram_report` یک tuple از پیام‌های HTML آماده ارسال برمی‌گرداند.
- عنوان بخش‌های ثابت با HTML bold نمایش داده می‌شوند.
- تمام متن‌های پویا با HTML escaping امن‌سازی می‌شوند؛ محتوای منبع، رویداد یا تحلیل به‌عنوان markup تفسیر نمی‌شود.
- متن‌های بلند با سقف پیش‌فرض محافظه‌کارانه ۳۹۰۰ کاراکتر به چند پیام تقسیم می‌شوند. موجودیت‌های HTML در هنگام شکستن خط نصف نمی‌شوند.
- منطق قالب‌سازی مستقل از Telegram SDK است و هیچ درخواست شبکه‌ای انجام نمی‌دهد.

## استفاده
```python
from apps.gold_market.telegram import render_telegram_report

messages = render_telegram_report(assessment, observations)
# ارسال واقعی عمداً خارج از این مرحله است.
```

هر عضو `messages` یک پیام HTML مستقل است و برای ارسال بعدی باید با `parse_mode=HTML` استفاده شود. سقف ۳۹۰۰ برای حاشیه ایمنی پایین‌تر از محدودیت رایج ۴۰۹۶ انتخاب شده است.

## ایمنی و محدودیت‌ها
- این مرحله فقط قالب‌ساز است؛ توکن ربات، شناسه کانال، کلاینت تلگرام و ارسال خودکار اضافه نشده‌اند.
- برچسب وضعیت داده‌ها، زمان، منبع، توضیحات، هشدارها و سلب مسئولیت گزارش مرحله G حفظ می‌شوند.
- نبود داده به عدد ساختگی تبدیل نمی‌شود.
- فعال‌سازی ارسال و زمان‌بندی به مراحل بعدی و تأیید جداگانه نیاز دارد.

python -m unittest discover -s tests -p "test_gold_market_*.py" -v

آزمون‌ها escaping متن پویا، تقسیم پیام بلند، حفظ موجودیت HTML، داده ناقص و سلب مسئولیت را پوشش می‌دهند.
