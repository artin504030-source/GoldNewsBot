# ربات سوم: Gold Market — مرحله A (Foundation)

## وضعیت

این شاخه فقط زیرساخت اولیه ربات سوم را اضافه می‌کند. هیچ‌یک از فایل‌ها یا Workflowهای دو ربات فعال خبر و قیمت تغییر نمی‌کنند. در این مرحله هیچ داده‌ای از اینترنت دریافت و هیچ پیامی به تلگرام ارسال نمی‌شود.

## مشخصات نسخه اول

- گزارش زنده و تحلیل وضعیت بازار طلا
- دوره گزارش: هر ۶۰ دقیقه
- شاخص‌ها: XAUUSD، DXY، US10Y، US02Y، USOIL، SPX و VIX
- بستر هدف: GitHub Actions
- زبان: Python
- گزارش تلگرام پس از تکمیل مراحل داده، تحلیل و تست فعال می‌شود.

## ساختار فعلی

- `apps/gold_market/config.py`: تنظیمات محیطی و کنترل دوره ۶۰ دقیقه
- `apps/gold_market/models.py`: مدل استاندارد مشاهده بازار با زمان و منبع داده
- `apps/gold_market/indicators.py`: فهرست رسمی هفت شاخص
- `tests/test_gold_market_foundation.py`: تست‌های پایه
- `.github/workflows/gold_market_tests.yml`: اجرای تست‌های مستقل این ماژول

## متغیرهای محیطی آینده

- `GOLD_MARKET_BOT_TOKEN`
- `GOLD_MARKET_CHAT_ID`
- `GOLD_MARKET_INTERVAL_MINUTES` (مقدار ثابت نسخه اول: `60`)
- `GOLD_MARKET_TIMEZONE` (پیش‌فرض: `UTC`)

توکن و شناسه کانال باید فقط در GitHub Actions Secrets/Variables ذخیره شوند؛ در کد یا فایل‌های مخزن قرار نگیرند. در این مرحله نیازی به افزودن Secret جدید نیست.

## مراحل بعدی

- B: انتخاب و اعتبارسنجی منابع داده و محدودیت پلن رایگان
- C: ساخت جمع‌آورنده داده
- D: اعتبارسنجی، تازگی و مدیریت داده ناقص
- E: تحلیل روند و روابط بین‌بازاری
- F: موتور امتیازدهی و Market Bias
- G: هشدار تغییر وضعیت
- H: قالب پیام تلگرام
- I: تست یکپارچه و سناریوهای خطا
- J: زمان‌بندی ساعتی و فعال‌سازی ارسال در GitHub Actions

## اجرای تست محلی

```bash
python -m unittest tests.test_gold_market_foundation -v
```

در این مرحله Workflow فقط تست‌ها را اجرا می‌کند؛ زمان‌بندی ارسال گزارش ساعتی در مرحله J فعال خواهد شد تا ربات ناقص یا داده ساختگی به کانال ارسال نکند.
