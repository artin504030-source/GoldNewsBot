# Gold Market — راهنمای راه‌اندازی

## منابع داده
- XAUUSD و DXY: Yahoo Finance Chart؛ وضعیت این داده‌ها `DELAYED` است و نباید قیمت زنده/لحظه‌ای تلقی شوند.
- US10Y و US02Y: سری‌های روزانه FRED به‌ترتیب DGS10 و DGS2.
- USOIL: سری روزانه WTI از FRED با شناسه DCOILWTICO.
- SPX: سری روزانه S&P 500 از FRED با شناسه SP500.
- VIX: سری روزانه VIX از FRED با شناسه VIXCLS.

## پیکربندی
کلید `FRED_API_KEY` برای دریافت واقعی سری‌های FRED لازم است. بدون آن، داده‌های FRED در دسترس نخواهند بود. داده‌ی جایگزین یا ساختگی تولید نمی‌شود.

## اجرای تشخیصی
از ریشه‌ی پروژه اجرا کنید:

```bash
python -m apps.gold_market
```

اجرای تشخیصی فقط خروجی JSON می‌دهد؛ ارسال تلگرام یا زمان‌بندی ساعتی هنوز فعال نشده است.

## کنترل‌های اعتبارسنجی — مرحله D
- زمان مشاهده باید timezone-aware باشد و بیش از ۵ دقیقه در آینده قرار نگیرد.
- حدود معقول برای هر شاخص بررسی می‌شود تا پاسخ خراب یا عدد ناممکن وارد گزارش نشود.
- داده‌ی `DELAYED` قدیمی‌تر از ۶ ساعت و داده‌ی `LIVE` قدیمی‌تر از ۳۰ دقیقه به `STALE` تبدیل می‌شود.
- داده‌ی `DAILY` قدیمی‌تر از ۵ روز (با درنظرگرفتن آخر هفته و تعطیلات) به `STALE` تبدیل می‌شود.
- داده‌ی نامعتبر رد می‌شود؛ داده‌ی کهنه حذف یا با مقدار ساختگی جایگزین نمی‌شود.

تست‌های آفلاین:

```bash
python -m unittest discover -v
```

تست‌ها با داده‌ی ساختگیِ محلی و بدون درخواست واقعی به API اجرا می‌شوند؛ بنابراین موفقیت آن‌ها به معنی تأیید دسترسی زنده به FRED یا Yahoo نیست.

## وضعیت اجرا
در این مرحله هنوز ارسال به تلگرام و اجرای خودکار هر ۶۰ دقیقه فعال نشده است. منبع Yahoo غیررسمی است و زمان تأخیر آن تضمین‌شده نیست.
