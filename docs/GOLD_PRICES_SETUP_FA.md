# راه‌اندازی ربات Gold Prices

## ویژگی‌ها
- ارسال قیمت XAU/USD هر ۳۰ دقیقه، همراه تغییر نسبت به حدود ۳۰ دقیقه قبل.
- منبع اصلی: XAUS (قیمت لحظه‌ای + تاریخچه درون‌روزی).
- منبع پشتیبان: Gold-API (قیمت لحظه‌ای).
- گزارش بازگشایی روزانه در ساعت ۰۸:۰۰ منطقه زمانی Australia/Sydney، از سه‌شنبه تا جمعه.
- گزارش بازگشایی هفتگی در دوشنبه ساعت ۰۸:۰۰ سیدنی.
- گزارش بسته‌شدن روزانه ساعت ۱۷:۰۰ America/New_York، دوشنبه تا جمعه.
- محاسبه گپ بر اساس آخرین قیمت بسته‌شدن ثبت‌شده؛ اگر مرجع قبلی موجود نباشد، صریحاً اعلام می‌شود.
- تشخیص خودکار DST از پایگاه زمانی IANA برای نیویورک و سیدنی.
- جلوگیری از ارسال تکراری با state ذخیره‌شده در مخزن.
- اگر هر دو منبع قیمت تازه ندهند، هیچ قیمت ساختگی ارسال نمی‌شود.

## منابع داده
- XAUS spot: https://xaus.com/api/v1/spot?compact=1
- XAUS intraday: https://xaus.com/api/v1/intraday?symbol=xau&hours=2
- Gold-API backup: https://api.gold-api.com/price/XAU

این نرخ‌ها قیمت مرجع اسپات هستند، نه bid/ask بروکر. هر پیام زمان داده و منبع را نشان می‌دهد.

## Secrets موردنیاز در GitHub
در Settings → Secrets and variables → Actions، این دو Secret را بساز:
- GOLD_PRICES_BOT_TOKEN: توکن ربات مستقل Gold Prices از BotFather
- GOLD_PRICES_CHANNEL_ID: شناسه کانال تلگرام (مثلاً -100...)

ربات تلگرام باید در کانال ادمین و مجاز به ارسال پیام باشد. توکن را در کد یا چت قرار نده.

## زمان‌بندی و محدودیت اجرا
GitHub Actions هر نیم‌ساعت اجرا می‌شود؛ اجرای زمان‌بندی‌شده ممکن است از سوی GitHub با تأخیر شروع شود. منبع زمان پیام، timestamp خود API است. زمان‌بندی در Python با timezoneهای America/New_York و Australia/Sydney محاسبه می‌شود.

## وضعیت اولیه
تا زمانی که دو Secret بالا تنظیم نشوند، ارسال تلگرام و تست واقعی کانال انجام نمی‌شود. پس از افزودن Secretها، اجرای دستی workflow برای تست اولیه لازم است.


## نمادهای چندبازاری

ربات در هر نوبت ۳۰ دقیقه‌ای، ۱۶ نماد را با یک درخواست دسته‌جمعی از BiQuote بررسی می‌کند:
- فلزات: XAUUSD، XAGUSD، XPTUSD، XPDUSD
- جفت‌ارزها: EURUSD، GBPUSD، USDJPY، AUDUSD، USDCAD
- شاخص‌ها: US30 (داوجونز)، USTEC (NAS100)، US500 (SPX500)، DE30 (DAX40)
- انرژی: USOIL (WTI)، UKOIL (برنت)، XNGUSD (گاز طبیعی)

برای این فید، کلید API یا Secret جدید لازم نیست. ربات فقط قیمت‌هایی را منتشر می‌کند که وضعیت بازارشان باز و زمان داده‌شان حداکثر ۵ دقیقه باشد؛ نماد فاقد قیمت تازه در پیام با وضعیت «در دسترس نیست» مشخص می‌شود. نمادهای شاخص و CFD ممکن است با نام بروکرهای مختلف تفاوت داشته باشند. گزارش‌های باز و بسته‌شدن سشن سیدنی/نیویورک فعلاً همچنان برای طلا هستند؛ پیام ۳۰ دقیقه‌ای همه نمادها را پوشش می‌دهد.
