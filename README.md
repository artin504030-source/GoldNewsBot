# GoldNewsBot

ربات خبری تلگرام برای خبرهای اقتصادی مرتبط با طلا. نسخه آزمایشی `gold-news-v2` قابلیت‌های امتیاز ارتباط با طلا، ساعت کابل، آرشیو اخبار، تشخیص تکرار بین فیدها، گزارش روزانه و هشدار خطای اجرا را اضافه می‌کند.

## اجرای آزمایشی
- Workflow اصلی در اجرای دستی از همان شاخه انتخاب‌شده استفاده می‌کند؛ اجرای زمان‌بندی‌شده روی `main` باقی می‌ماند.
- گزارش روزانه هر روز ساعت ۲۰:۰۰ کابل (۱۵:۳۰ UTC) اجرا می‌شود.
- تقویم رویدادها از فید عمومی Forex Factory خوانده می‌شود؛ در صورت در دسترس نبودن فید، گزارش این محدودیت را اعلام می‌کند.
- داشبورد در `dashboard/index.html` قرار دارد. برای نمایش آنلاین باید GitHub Pages جداگانه فعال شود؛ فعلاً هیچ تنظیم عمومی در مخزن تغییر داده نشده است.

## Secrets
در GitHub Actions باید `BOT_TOKEN` و `CHANNEL_ID` تنظیم باشند. توکن هرگز نباید در فایل‌های مخزن ذخیره شود.
