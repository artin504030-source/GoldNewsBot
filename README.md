# GoldNewsBot

ربات خبری تلگرام برای خبرهای اقتصادی مرتبط با طلا. نسخه آزمایشی `gold-news-v2` قابلیت‌های امتیاز ارتباط با طلا، ساعت کابل، آرشیو اخبار، تشخیص تکرار بین فیدها، گزارش روزانه و هشدار خطای اجرا را اضافه می‌کند.

## اجرای آزمایشی
- Workflow اصلی در اجرای دستی از همان شاخه انتخاب‌شده استفاده می‌کند؛ اجرای زمان‌بندی‌شده روی `main` باقی می‌ماند.
- گزارش روزانه هر روز ساعت ۲۰:۰۰ کابل (۱۵:۳۰ UTC) اجرا می‌شود.
- تقویم رویدادها از فید عمومی Forex Factory خوانده می‌شود؛ در صورت در دسترس نبودن فید، گزارش این محدودیت را اعلام می‌کند.
- داشبورد در `dashboard/index.html` قرار دارد. برای نمایش آنلاین باید GitHub Pages جداگانه فعال شود؛ فعلاً هیچ تنظیم عمومی در مخزن تغییر داده نشده است.

## Secrets
در GitHub Actions باید `BOT_TOKEN` و `CHANNEL_ID` تنظیم باشند. توکن هرگز نباید در فایل‌های مخزن ذخیره شود.


## پایش خبر فوری و تأیید چندفیدی
- Workflow جداگانه `breaking_news.yml` هر ۵ دقیقه فقط فیدهای اولویت‌دار بانک‌های مرکزی، داده‌های اقتصادی و ژئوپلیتیک را بررسی می‌کند.
- اسکن سریع فقط خبرهای دارای عبارت‌های اضطراری/حساس را انتخاب می‌کند و خبرهای عادی را در `seen_news.json` علامت‌گذاری نمی‌کند؛ بنابراین اسکن عادی ۱۵ دقیقه‌ای همچنان آن‌ها را بررسی خواهد کرد.
- خبرهای تکراری بین فیدها دوباره ارسال نمی‌شوند؛ فیدهای دیگری که همان خبر را منتشر کنند در آرشیو به‌عنوان تأییدکننده ثبت می‌شوند. این شمارش، تأیید در چند فید است و لزوماً به معنی راستی‌آزمایی مستقل ناشران نیست.
- دو Workflow از گروه هم‌زمانی مشترک و فایل‌های سابقه مشترک استفاده می‌کنند تا روی هم ننویسند.
- زمان‌بندی ۵ دقیقه‌ای GitHub ممکن است با تأخیر اجرا شود و تضمین لحظه‌ای نیست. زمان‌بندی خودکار فقط پس از انتقال Workflow به شاخه پیش‌فرض مخزن فعال می‌شود؛ در شاخه آزمایشی، اجرای دستی برای تست استفاده می‌شود.


## مرحله سوم: آرشیو و گزارش روزانه
- داشبورد `dashboard/index.html` آرشیو را از `news_archive.json` می‌خواند و جست‌وجو بر اساس عنوان، خلاصه، منبع، دسته، اهمیت، تاریخ انتشار و امتیاز ارتباط با طلا دارد.
- داشبورد آمار کل خبرها، خبرهای با اهمیت زیاد، میانگین امتیاز ارتباط با طلا و تعداد خبرهای ۲۴ ساعت اخیر را نمایش می‌دهد.
- برای انتشار داشبورد، در تنظیمات مخزن GitHub از بخش **Pages**، گزینه **Deploy from a branch** و شاخه `main` یا شاخه‌ای که می‌خواهید آزمایش کنید را انتخاب کنید؛ پوشه `/ (root)` را به‌عنوان منبع انتخاب کنید. سپس صفحه `https://<username>.github.io/<repository>/dashboard/` در دسترس خواهد بود. تا قبل از فعال‌سازی Pages، داشبورد فقط به‌صورت فایل HTML در مخزن است.
- گزارش روزانه ساعت ۲۰:۰۰ کابل، تعداد خبرها بر اساس اهمیت و دسته، خبرهای دارای امتیاز بالاتر، منابع ثبت‌کننده و رویدادهای تقویم را نشان می‌دهد.
- زمان رویدادهای Forex Factory فقط وقتی به کابل تبدیل می‌شود که منطقه زمانی منبع به‌طور معتبر معلوم باشد؛ در فید فعلی منطقه زمانی مشخص نیست، پس زمان خام همراه با هشدار نمایش داده می‌شود.
- اجرای دستی گزارش با `dry_run=true` فقط پیش‌نمایش می‌سازد و به تلگرام پیام نمی‌فرستد.
