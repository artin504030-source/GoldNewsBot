# اسکلیت توسعه GoldNewsBot

این بسته یک اسکلیت مستقل و قابل ادغام برای توسعه مرحله‌ای GoldNewsBot است.
فایل‌های فعلی ربات را حذف یا جایگزین نمی‌کند. ابتدا در پوشه جداگانه ساخته شده تا پس از بررسی، با مخزن اصلی ادغام شود.

## اجزای موجود
- لایه‌بندی `app/core` و `app/platform` برای جداسازی تنظیمات و زیرساخت
- فرمان سلامت واقعی برای بررسی اتصال و صحت پایگاه داده
- مستندات معماری، زیرساخت و نقشه انتشار مرحله‌ای
- تنظیمات متمرکز از متغیرهای محیطی
- مدل استاندارد خبر
- رابط منبع خبر و ارسال تلگرام
- خط لوله دریافت، حذف خبر تکراری و ارسال
- ذخیره شناسه خبرهای پردازش‌شده در SQLite
- ثبت لاگ
- بررسی سلامت
- تست‌های واحد بدون نیاز به توکن واقعی یا اتصال اینترنت

## راه‌اندازی
1. Python 3.11 یا جدیدتر نصب باشد.
2. فایل `.env.example` را به `.env` کپی کنید.
3. مقدار `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را فقط در فایل محلی `.env` وارد کنید.
4. نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

5. اجرای تست‌ها:

```bash
python -m unittest discover -s tests -v
```

6. بررسی سلامت:

```bash
python -m goldnewsbot --health
python -m app.main health
```

## نکته مهم
این نسخه عمداً منبع خبر زنده یا ارسال خودکار زمان‌بندی‌شده را فعال نمی‌کند.
اتصال به منابع فعلی مخزن، مترجم/تحلیل‌گر هوش مصنوعی و زمان‌بندی GitHub Actions در مرحله ادغام انجام می‌شود.
تا زمانی که تنظیمات تلگرام وارد نشده باشد، هیچ پیام واقعی ارسال نمی‌شود.
